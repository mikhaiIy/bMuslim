# Shared almanac UI — design judgment round 1

## Decision

**82/100 — ITERATE.** No P0.

The judge accepted the one-renderer/flavor-owned-content direction and required four P1 clauses:
an explicit point/interval/render-policy DTO; atomic model-key ownership across motion/drag/focus;
exact production folio boundary/scroll/focus/copy behavior; and concrete shared-identity/tests/APK
proof. All four are incorporated into the revised execution brief.
