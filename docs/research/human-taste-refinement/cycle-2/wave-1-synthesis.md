# Cycle 2, wave 1 synthesis

This is a provisional contract, not a visual selection or research pass.

## Evidence authority

- Current model/renderer/tests are highest product authority. They prove overlaps, fardhu-first
  sorting/ledger, independent prayer/context emphasis, parallel summaries, clipping geometry, and
  current semantics. Runtime appearance remains uncaptured.
- JAKIM/Mufti Wilayah appropriately distinguish obligatory/additional worship and iqamah nuance;
  they do not validate prototype 20-minute windows, inclusive endpoints, or commands to abandon a
  valid practice when prayer time merely begins.
- Android/Compose sources directly govern semantics, traversal, scaling, insets, measurement,
  animation tests, and duration scale.
- WCAG governs outcomes, not Compose APIs.
- Carbon/Spectrum/Apple transfer hierarchy principles, not enterprise controls/layout.
- Attention/UEyes evidence is indirect; it supports controlled first-read comparison, not exact
  salience prescriptions.
- Clock proxy calculations locate failure regions but do not certify font pixels.

## Provisional contract

### Ownership

Pure moment ownership: active fardhu optional, primary contextual optional/next, tertiary day state.
With active fardhu, full name/start/state/node and first spoken position are non-suppressible.
Context arc may remain but title cannot share primary emphasis. Exact boundary truth applies.

### Visual hierarchy

At most one primary textual role. Hierarchy uses two non-color channels. Compact/high type stacks
or discloses before shrinking prayer. Outside overlap, dual scaffold collapses.

### Geometry

Measure text with real density/font/direction. Place fardhu first against safe/hard regions; place
secondary afterward. Hard: edges/aperture, pointer contact, fardhu text/time/node/halo, controls.
Suppression order: celestial, passive hours, upcoming explanation, contextual title, contextual arc
only if meaning exists elsewhere. Every retained label has safe placement or external fallback.

### Clock/header

All clock ink/header groups remain in a measured header-safe rect and outside aperture at every
progress/direction. Overlay has one safe instance; fade-through has at most one, safe endpoints,
exclusive thresholds, bounded gap. Reserve/reflow destination metadata before strategy comparison.

### Motion/semantics

Ownership pure from minute; visual role pure from progress/strategy; retargeting cannot restore
contextual primacy. Spoken: time → fardhu once → context → day state if useful. No drag live spam.
Canceled destinations emit nothing. Reduced motion reaches one complete valid state.

## Exactly two wave-2 validations

### 1. Reproducible overlap + clock geometry matrix

Create isolated persisted harness outside app production code, preferably exact project Compose and
`TextMeasurer`; otherwise state blocker and label fallback metrics. Inputs: all overlap ±10; 360/390;
insets 0/24/36; scales 1.0/1.3/1.6 and 2.0 if supported; p every .05 plus reversals; four clock
strings; dual A/B/C; clock overlay/fade. Derive fardhu owner first. Measure bounds/baselines/overflow,
leaders/hard intersections, safe containment, clock count/gap, direction equality.

Pass: one readable fardhu primary; secondary never suppresses it; safe secondary/fallback; safe
header/clock; overlay count 1 or fade count ≤1 with declared gap; deterministic/direction-equivalent;
correct boundaries; no overflow/baseline failure; worst compact adaptively solved.

Return executable source/command/versions/raw data/summary, first counterexamples, debug renders,
and limitations. Feasibility only, no visual winner.

### 2. Accessibility + transition ownership audit

Build isolated exhaustive state model for overlap boundaries/interiors; stable/scrub/settle/
transition/reversal; target/last-settled; normal/zero/app-reduced hypotheses; compact/high type;
range edge requests. Require one value owner, one canonical adjustable owner, zero semantic clocks;
nonduplicative fardhu-first speech; minute-driven ownership; settled subtree policy; no alpha-only
hiding; valid zero-motion endpoint; consistent quantized range; reachable traversal.

Pass: one time owner every state; fardhu once and first; no double primary/early focus/hidden action/
stale effect; exact boundary truth; valid zero-motion; safe cyclic adjustment; direction-independent
semantics; automated assertions separated from TalkBack/OEM claims.

Return API authority/version table, state diagram, executable checker/raw results, representative
semantics trees, current-code counterexamples, later UI assertions, and manual matrix.
