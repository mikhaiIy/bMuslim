## New evidence

### Rich designer rationale beats ratings alone

- **Source:** Jason Wu, Amanda Swearngin, Arun Krishna Vajjala, Alan Leung, Jeffrey Nichols, and
  Titus Barik, “Improving User Interface Generation Models from Designer Feedback,” CHI 2026,
  published January 2026.
- **Primary pages:**
  https://machinelearning.apple.com/research/designer-feedback and
  https://doi.org/10.1145/3772318.3791567
- **Evidence:** 21 designers produced roughly 1,500 annotations through familiar commenting,
  sketching, and direct-revision workflows. Models trained from this richer designer-aligned
  feedback outperformed models trained from conventional rating/ranking feedback and the tested
  baselines.
- **Transfer:** Keep critiques concrete and reparative: element + minute/state/progress + defect +
  consequence + bounded correction. A numeric score is a gate summary, never the design feedback.
- **Current implementation:** the independent research, image, and implementation judgments
  already use this format and reject whole rounds when a local ownership or geometry defect remains.

### Prompt-only taste converges and disconnects authorship

- **Source:** Aigerim Kurmanbekova, Itzel Lopez, Monica Chen, and Adrienn Juhasz, “Aesthetic Taste
  and Its Limits: Breakdowns in Prompt-Mediated Design of User Interfaces,” UC Berkeley School of
  Information, updated May 12, 2026.
- **Primary page:**
  https://www.ischool.berkeley.edu/programs/mims/projects/2026/aesthetic-taste-and-its-limits-breakdowns-prompt-mediated-design-user
- **Evidence:** 13 observed design sessions identified vocabulary and execution gaps, generic-style
  convergence, a tacit ceiling, authorship disconnect, and risk-reward freeze. The recommended
  directions include visual input as specification, local intent-anchored editing, safer versioned
  iteration, and visible co-creative authorship.
- **Transfer:** Do not ask an agent to “make the wheel beautiful” in one pass. Compare controlled
  visual states, keep the selected minute and geometry fixed between alternatives, preserve round
  history, and issue bounded corrections against a named intent.
- **Current implementation:** separate full-resolution state images, retained rejected variants,
  research/design locks, and narrow executor rounds already provide those controls.

### Generic correctness is not product identity

- **Source:** Tanya Donska, “AI Makes Bad Design Look Good Enough,” Built In, June 11, 2026.
- **Page:** https://builtin.com/articles/ai-design-slop-era
- **Evidence:** technically correct but interchangeable flows and components erase product-specific
  identity; decorative motifs persist after their functional reason disappears.
- **Transfer:** Every visible wheel primitive must communicate prayer-time, selected-time, source
  status, interaction ownership, or disclosure structure. Remove motifs that only signal generic
  polish.
- **Current implementation:** the almanac instrument, fardhu-first hierarchy, selected readout,
  source-aware interval grammar, and structural paper aperture have product roles. Cards, pills,
  glass, decorative mosque imagery, and aesthetic-only motion remain banned.

### Make agent decisions inspectable and audits deterministic where possible

- **Sources:** Jonathan Gordon, “Black box AI drift,” Stack Overflow, April 23, 2026; Adrian Krebs'
  deterministic Show HN audit as summarized by Developers Digest, updated June 10, 2026.
- **Pages:**
  https://stackoverflow.blog/2026/04/23/black-box-ai-drift-ai-tools-are-making-design-decisions-nobody-asked-for/
  and https://www.developersdigest.tech/blog/ai-design-slop-and-how-to-spot-it
- **Evidence:** hidden assumption drift is a production risk; deterministic DOM/style checks can
  expose repeated generic patterns more reliably than asking another model for an ungrounded vibe
  score.
- **Transfer:** Persist locks, source truth, state matrices, code diffs, build/test evidence, and
  explicit unproven device conditions. Use pure geometry and semantics tests for measurable claims;
  reserve human/creative judgment for perceptual quality.
- **Current implementation:** pure selection, geometry, collision, reveal, range, and semantics
  contracts are tested, while device raster, assistive technology, OEM font, and interruption
  behavior remain explicitly conditional.

## Freshness decision

The 2026 evidence strengthens the existing process rather than selecting a new aesthetic. The
locked direction remains valid because it already uses visual-first comparison, rich defect
rationale, bounded local repair, versioned rejected alternatives, deterministic contracts, and a
product-specific devotional grammar. No new broad wheel ornament, layout family, or motion effect
is authorized by this audit.
