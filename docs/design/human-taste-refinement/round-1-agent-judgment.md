# Round 1 independent design judgment

## Verdict

**74/100 — REJECT.** The round does not meet the required 90/100 threshold and it fails hard
gates. The images establish a credible visual world, a useful maximum-type composition, and one
promising clock family, but they do not yet prove a stable selected-deed readout through touch and
transition.

### Hard-gate result

- **Failed: stable, unambiguous pointer relation.** In C touch, the selected saffron hand terminates
  near the wheel centre while a separate vertical leader descends from an unrelated lower-left
  point to the readout. The user has to infer which line owns `Waktu Subuh · 05:59` exactly when
  direct manipulation should make ownership clearest.
- **Failed: banned dashboard/card treatment.** Clock F places the destination time in a wide dashed,
  rounded rectangle with a clock icon. This reads as a status widget and is neither the specified
  fixed detail-header clock nor the quiet unboxed handoff requested by the brief.
- **Failed as a controlled comparison.** B, C touch, and the two midpoint images materially change
  wheel/readout geometry rather than changing only the named hypothesis. That prevents the images
  from proving which strategy caused the improvement.
- No screen visibly clips the principal `05:59` digits. The two clock concepts do avoid the original
  bisected-clock defect in their isolated frames, but one forward midpoint is not sufficient path,
  reverse, or interruption evidence.

## Selection

**Label: A is the strongest round-one hypothesis, but it is not implementation-locked.** It has the
clearest leader, stable shared origin, and strongest prayer/context hierarchy. C contributes the
better touch behavior—full prayer plus pruned context—but its generated touch frame destroys the
stable origin. The credible direction is therefore **A's fixed pointer stack with C's
touch/settle content policy**, not C's changing placement.

**Clock: O is the strongest round-one strategy, but only as the round-two challenger.** Its one
intact run preserves continuity and avoids the visible cut. F is not judgeable because the frame
replaced the specified header handoff with a dashboard widget and changed the wheel geometry. O
still needs controlled 25/50/75, reverse, interruption, and reduced-motion endpoint evidence before
production selection.

## Smallest executable round-2 direction

Do not regenerate seven broad concepts. Produce one controlled four-frame correction plus one
adaptive check:

1. **Lock a single base geometry.** Reduce `bMuslim` to a small 18–20sp identity line; keep the date
   in one quiet metadata row; reserve an explicit measured clock corridor; keep wheel centre,
   diameter, selected minute, sheet edge, and all prayer nodes identical across regular frames.
2. **Build one protected reading bay from A.** Keep the same left-aligned primary origin and the same
   single elbow leader at settled and touch. The bay is an unboxed, opaque pine knockout in the
   wheel's quiet interior—not a card, pill, blur, or gradient. It owns measured text bounds above
   rotating marks. Settled shows `Waktu Subuh · 05:59` then `Amalan berkaitan · Zikir pagi`; touch
   changes only the second line to `Zikir pagi`. The origin and leader do not move.
3. **Show the corrected pair.** Generate settled 05:59 and direct-touch 05:59 using identical pixels
   outside the halo and secondary copy. The touch halo stays behind the selected node. The paper
   edge reduces to 12dp during touch.
4. **Prove O rather than restyle it.** Generate O at 25%, 50%, and 75% from the same geometry, with
   the one measured clock run entirely inside the reserved corridor. Make reverse use the same 50%
   frame. Define a structural threshold where the wheel readout yields to the sheet disclosure;
   never let both compete. Reduced motion jumps to the destination anchor and endpoint layout.
5. **Repeat one adaptive endpoint.** Keep the successful 2× vertical recomposition, add the short
   wheel-to-header relational leader, soften the CTA chevron, and prove the same primary/secondary
   reading order without relying on the green hue.

The next judge should compare rectangle overlays or annotated safe regions alongside the clean
images. Raster beauty is not evidence of measured Android bounds, but consistent rectangles will
make the intended production contract auditable. A pass is plausible without inventing a new
visual system: preserve the existing material world, fix ownership geometry, and remove the
brand/widget distractions.
